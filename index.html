Engine Evaluation
Usable Now
WebGL Rendering Pipeline
Browser-native WebGL runtime immediately applicable for lightweight hero visualizers, 3D card inspection tools, and tactical prototypes — no Unreal download required.
Usable Now
Turn / State Logic Framework
Core state management maps cleanly to card activation systems, tarot-style rules, and Duet chess mechanics. Turn order and state sync are ready to reuse.
Usable Now
Lightweight Asset Loading
Asset ingestion routines handle lower-poly models, textures, and UI overlays well — ideal for web frontends and companion apps hosted on LoptrLab.com.
Gap — Requires UE5
High-Fidelity Paragon Assets
Epic's 39+ hero packages (Skeletal Meshes, Niagara VFX, Animation Blueprints) exceed browser memory limits without significant poly-reduction and shader rewrites.
Gap — Must Build
Network Replication & Real-Time Physics
High-tickrate client-side prediction, server reconciliation, and continuous 3D collision detection are native to Unreal Engine — not present in the current web engine. These must be authored from scratch for a full 3v3+ action game.

Integration Strategy
LAYER 01 — WEB
veiled-dominion-engine
  • Interactive Deck Builder & Lore Viewer with 3D hero card inspection
  • Rapid prototype for game rules, card interactions, and tactical logic
  • Companion app integration at LoptrLab.com
  • Validate C++ port targets before Unreal migration
LAYER 02 — UNREAL ENGINE 5
Core 3D Action Game
  • Pre-rigged Paragon hero files, imported and configured via GAS
  • Niagara visual effects from Epic's ability packages
  • Network replication & physics via Unreal's native systems
  • Clean C++ module architecture for open-source contribution
Design System Note

The card & tarot system — inspired by Rider-Waite structure and Mage: The Ascension archetypes — requires custom 2D illustration, UI frame design, and Blueprint mechanics to manage deck states, card draws, and passive/active abilities. Epic provided the 3D world; the card layer is original IP.

About

Dominique — ibloud

Independent creative technologist running Loptr Lab and Urban Alien Adventures. Working at the intersection of game design, modular engine architecture, and worldbuilding — with a focus on building systems that can be contributed to and extended by a community.

The Return to the Void project merges an open-source MOBA framework with a custom character deck system — drawing on clean code principles (Clean Coders, Tom Looman's Unreal tutorials) and open collaboration. The visual foundation is Epic's released Paragon hero packages. The architecture, card system, and narrative layer are built here.
