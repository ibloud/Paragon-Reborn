# 50 Ways to Leave Another — Suno Realization Evidence

## Purpose

This record separates the human-originating work from the later Suno realization and preserves the current account state shown in the supplied Suno screenshot.

The provenance model is intentionally **human-first**:

**Human-generated/original work**
→ original song, lyrics, recording, production/session evidence

**Later Suno realization**
→ Suno track and any later vocal/arrangement experimentation

**Implementation**
→ MIDI/transcription → Synthesia → web presentation

## 4. Do not collapse the layers

The project should continue to distinguish:

1. **Human-authored composition and lyrics**
2. **Original human recording / Pro Tools session**
3. **Recording and mixing services**
4. **Suno realization**
5. **Any later vocal/arrangement exploration**
6. **MIDI/transcription**
7. **Synthesia presentation**
8. **Web demonstration**

A later AI realization does not erase the earlier human-originating evidence. Conversely, the existence of a human-originating source does not by itself establish what copyright protection, ownership, or contractual rights attach to every later AI-generated element.

- creation date/time;
- generation/version/model information;

Do **not** list a downloaded audio file, WAV/MP3/stems, or a local SHA-256 hash as existing evidence unless such an artifact is actually downloaded and preserved later.

The current screenshot is useful evidence of **present account state, the displayed track, and the moderation notice**, but it should not be used as proof of historical subscription status or as a substitute for the original creation/history records.
