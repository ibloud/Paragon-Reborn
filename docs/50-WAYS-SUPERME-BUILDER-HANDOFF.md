# 50 Ways / SuperMe.ai Builder Handoff

This repository is the Layer 3 game/narrative destination identified by the 50 Ways project handoff.

## Build boundary

Paragon ReBorn is described as a game-development sandbox with a training/externship pipeline. The durable implementation boundary is:
- original rules and gameplay systems;
- telemetry and accessibility;
- PIXIE interface/integration;
- training curriculum;
- documentation;
- separately tracked third-party marketplace assets.

Third-party assets remain governed by their applicable licenses. Do not represent them as original project IP.

## Required continuity

Builders should preserve the separation between:
1. original project systems;
2. licensed marketplace assets;
3. proposed/researched material;
4. separate IP domains.

The 50 Ways handoff says the game layer is replaceable: the underlying architecture and training pipeline should survive if marketplace assets or their licensing terms change.

## Builder success criteria

A useful contribution should make it possible to verify:
- whether a trainee can complete the externship pipeline and produce a playability card without project-owner intervention;
- whether the rights-clean development-layer chart remains intact;
- which parts of a contribution are original, licensed, proposed, or separately governed.

## Naming/legal gate

The supplied handoff states that the PARAGON name cannot be used under the applicable Epic restriction and that rebranding is required.

Do not make new public naming, rights, affiliation, or clearance claims without routing them through the project's established review boundary.

## First contribution

Start with one bounded task. Prefer:
- training/playability-card tooling;
- accessibility;
- documentation;
- asset/license inventory;
- engine-independent rule schemas;
- tests and validation.

If the task crosses a legal boundary, stop and flag the question rather than guessing.
