# Decision: original tarot hero and story direction

Status: owner-approved direction; proposed mechanics, documentation implemented in this change.  
Date: 2026-10-08. Tracking: #16.

Use tarot as a shared vocabulary for hero tensions, build choices and authored story variation. Start the new runtime with original archetypes and placeholders. Historical Paragon assignments remain research and do not define a replacement roster or grant content rights.

The normative design proposal is [ORIGINAL_HERO_CARD_DIRECTION.md](../ORIGINAL_HERO_CARD_DIRECTION.md); content admission follows [ORIGINAL_CONTENT_RIGHTS.md](../ORIGINAL_CONTENT_RIGHTS.md). Existing v1 rules remain unchanged. One-hero proof precedes three-hero expansion. Balance requires measured gameplay evidence; story selection requires deterministic replay and meaningful consequences.

Rejected: automatic power from card number; renaming legacy heroes as an IP migration; recreating their stories; generative models deciding rules; importing this experiment into canonical four-player Veiled Dominion; immediate full-roster or MOBA implementation.

Repository owners: this hub owns the source design and future rules version; Loptr-Lab/veiled-dominion-engine owns the isolated receiving experiment contract. Other games, bots and Codex surfaces need explicit adapters before adopting it. Open asset PR #13 remains separately reviewable.
